# Security Policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/majiayu000/crawlume/security/advisories/new) with
the affected version, reproduction steps and impact. You will receive an acknowledgement within
5 business days.

## Scope

In scope: SSRF and URL-policy bypasses, credential or browser-profile leakage, control-plane
authentication and tenant isolation, API key and worker key handling, and injection through crawled
content.

Out of scope: rate limits or blocks imposed by third-party sites, and findings that require a
compromised host.

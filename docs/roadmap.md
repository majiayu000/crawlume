# Diaoyan 路线图

## v0.1 已完成

- 单页 HTTP 读取。
- 真实 Chrome 渲染回退。
- Readability 与 Markdown 提取。
- SQLite 成功结果缓存。
- SSRF、robots、重定向、超时和响应大小保护。
- 专用授权 Profile。
- CLI 与 MCP。
- 结构化错误和读取证据。

## v0.2 站点读取（已完成）

- `map`：同域 URL 发现、深度和页数限制、部分失败报告。
- `crawl`：边发现边读取正文，返回成功页与逐页错误。
- 默认串行和有界规模，避免对网站制造突发流量。
- CLI 与 MCP 使用同一实现。
- 测试站点范围、去重、查询参数、深度、截断和失败语义。

## v0.3 搜索发现（已完成）

- Provider 无关的搜索服务边界。
- SearXNG JSON Provider，支持本地自建实例。
- `search` CLI 与 `search_web` MCP 工具。
- 标准化结果、分页、语言、安全搜索和时间范围。
- 未配置、JSON 禁用和异常响应的显式失败。

## v0.4 可靠性

- 持久任务队列、恢复和取消。
- 域名级速率限制与有界退避。
- 浏览器 Worker 池与授权 Profile 串行化。
- 运行成功率、失败原因和成本统计。
- 变化检测和定时监控。

复杂内容质量评分、LLM Judge、Embedding 和跨页语义去重暂不进入核心路线。只有真实客户问题和成本收益证据足够时再单独评估。

## v0.5 身份与许可

- 公开 Agent 身份说明。
- Web Bot Auth 签名。
- RSL 发现与 License Token。
- 许可、预算和用户确认策略。
- 访问与内容使用审计。

## v0.6 服务化

- 多租户认证、项目和 API Key。
- 配额、计量、账单和 Webhook。
- 控制台、任务历史和质量监控。
- 私有部署、安全基线和运维手册。

## 发布门槛

每个阶段都必须具备：稳定输入契约、显式失败、SSRF 与凭证隔离、聚焦测试、真实公开站点冒烟，以及升级后不降低既有安全边界的证据。

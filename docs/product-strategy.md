# Diaoyan 产品策略

## 定位

Diaoyan 是面向 AI Agent 的可信网页访问层：稳定读取、明确失败、用户授权、来源可追溯。

它不承诺“任何网站都能读”，不伪装第三方机器人，不自动破解验证码、登录或付费墙。

## 用户与产品面

### 免费本地版

面向开发者、研究人员和 AI 重度用户：

- CLI、MCP。
- HTTP 与本机 Chrome。
- 用户主动创建的专用授权 Profile。
- 单页读取、站点 Map、Crawl、批量读取。
- 通过用户自建 SearXNG 提供搜索发现。
- 本地缓存、内容哈希和明确错误。

本地版承担获客、信任建立和真实使用反馈，不依赖外部付费 API。

### ToC Pro

用户购买的是研究和监控结果，而不是“爬虫”：

- 浏览器插件，一键把当前页面交给 Agent。
- 定时监控和变化提醒。
- 项目、标签、全文搜索和引用存档。
- 跨设备同步和批量任务。
- 本地凭证，云端只运行用户明确提交的任务。

### ToB Gateway

企业购买的是稳定性、权限控制、审计和运维：

- 多租户 API 和 MCP Gateway。
- 项目、团队、API Key、额度与账单。
- Worker 队列、并发限制、Webhook 和 SLA。
- 域名策略、授权 Session 保险箱和私有部署。
- 访问身份、许可、内容证据和成本审计。

## 访问策略

| 页面状态 | 默认行为 |
|---|---|
| 公开且允许 | HTTP 读取 |
| JavaScript 壳或正文不完整 | 使用真实 Chrome |
| 用户自己的登录内容 | 使用专用授权 Profile |
| 需要机器可读许可或付费 | 等待明确授权或预算确认 |
| robots 禁止 | 停止 |
| 401、402、403 | 明确失败，不伪装其他机器人 |
| 429、临时 5xx | 有界退避，不旋转身份规避限制 |

## 产品护城河

- 本地与云端混合执行，降低成本并保护凭证。
- 访问结果带证据，不只返回一段 Markdown。
- 统一权限和许可策略，而非把风险推给每个 Agent。
- 兼容多个 Agent 表面和开放协议。
- Provider 可替换的搜索发现与统一读取链路。
- 对站点行为建立可复现的质量基准和回归测试。

## 商业原则

- 基础本地读取免费。
- ToC 对同步、监控、批处理和工作流收费。
- ToB 按成功页面、浏览器时间、任务和企业能力计费。
- 高成本路径必须独立计量，不能销售不可持续的无限套餐。
- 不以绕过付费墙、验证码或站点明确封禁作为卖点。
